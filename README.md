# Leaf Disease Detection

Research code for leaf-image classification experiments using CNN architectures, Vision Transformers, and an EfficientNet-B0 + ViT-B/16 hybrid model.

## Repository structure

```text
leaf-disease-detection/
├── notebooks/
│   ├── 01_leaf_dataset_and_model_experiments.ipynb
│   └── 02_hybrid_model_training.ipynb
├── data/README.md
├── checkpoints/README.md
├── requirements.txt
├── .gitignore
└── README.md
```

## Notebooks

### 01. Dataset and model experiments
- Dataset inventory, label/taxonomy mapping, image-quality checks, and duplicate-image analysis
- Stratified data-split preparation
- EfficientNet-B0, ResNet50, and DenseNet121 experiments
- ViT + LSTM and pure ViT-B/16 experiments
- Evaluation, visualization, model comparison, and model export

### 02. Hybrid model training
- Dataset audit and preparation steps
- Pure ViT-B/16 checkpoint/evaluation workflow
- EfficientNet-B0 + ViT-B/16 feature extraction and fusion
- Hybrid cross-validation, test evaluation, comparison, and output packaging

The notebooks retain the original research cells. Saved cell outputs were cleared to keep the repository lighter. Optional Kaggle kernel-output recovery commands are disabled so they do not run unexpectedly.

## Dataset setup

The dataset is not included in this repository. Obtain it from its authorized source and follow its license/usage conditions.

Both notebooks use a configurable dataset path. Set the environment variable `LEAF_DATASET_ROOT` to the directory named `leaf-detection` that contains the source dataset folders. The default preserves the original Kaggle path:

```text
/kaggle/input/datasets/afsanatusa05/leaf-detection
```

Expected structure (the long archive-folder names must match your actual dataset):

```text
leaf-detection/
├── Our research pictures-.../
│   └── Our research pictures/
└── Medical plants-.../
    └── Medical plants/
```

For a local run, set `LEAF_DATASET_ROOT` before starting Jupyter. Example:

```bash
# Linux/macOS
export LEAF_DATASET_ROOT="/absolute/path/to/leaf-detection"

# Windows PowerShell
$env:LEAF_DATASET_ROOT = "D:\datasets\leaf-detection"
```

The notebooks also use `LEAF_OUTPUT_DIR` for generated files. Its default is `./outputs`.

## Environment

Python with PyTorch and torchvision is required. A GPU runtime is strongly recommended for model training, particularly ViT-B/16 and the hybrid model.

```bash
pip install -r requirements.txt
```

Install a PyTorch build compatible with your CUDA/runtime using the official PyTorch installation selector if the default pip build is not suitable.

## Checkpoints and generated artifacts

Trained weights and dataset images are not included. Some evaluation/recovery cells expect checkpoints generated by earlier training cells, including files such as `best_vit.pth` and `best_vit_lstm.pth`. Run the corresponding training cells first or provide the matching checkpoint files at the paths used in the notebook.

Do not commit large `.pth` files directly without checking GitHub's file-size limits. Use Git LFS or GitHub Releases if checkpoint distribution is needed.

## Reproducibility

- Use the same dataset version and class-folder structure used in the experiments.
- Preserve the generated split files when reproducing a particular run.
- Record Python, PyTorch, torchvision, CUDA, and GPU versions for each run.
- Dataset access and trained weights are distributed separately from this code repository.
